# BUG-002 — Les prix changent après actualisation avec `visual_user`

- **ID :** BUG-002
- **Titre :** Les prix affichés changent après actualisation de la page
- **Application :** SauceDemo
- **Compte de test :** `visual_user`
- **Cas de test associé :** TC-EDGE-004
- **Sévérité proposée :** Élevée — à confirmer selon les critères du projet et l'impact constaté
- **Statut :** Ouvert / à investiguer

## Préconditions

- Ouvrir SauceDemo.
- Se connecter avec le compte de test `visual_user`.
- Afficher le catalogue des produits.

## Étapes pour reproduire

1. Noter ou capturer les prix affichés dans le catalogue.
2. Actualiser la page.
3. Comparer les prix après actualisation avec ceux observés avant.

## Résultat attendu

Les prix des mêmes produits restent cohérents après actualisation, sauf changement explicitement prévu par l'application.

## Résultat observé

Selon l'observation réalisée pendant le test, les prix des produits changent après actualisation de la page.

## Preuves

- Avant actualisation : `TC-EDGE-004_visual-user-before.png`
- Après actualisation : `TC-EDGE-004_visual-user-after.png`
- Ajouter les captures réelles dans le dossier `evidence/` et vérifier que les noms correspondent.

## Impact potentiel

Des prix incohérents peuvent induire l'utilisateur en erreur et diminuer la confiance dans les informations commerciales affichées.

## Informations complémentaires

Anomalie observée pendant un test manuel. Date, navigateur et système d'exploitation à compléter si ces informations ont été relevées.
